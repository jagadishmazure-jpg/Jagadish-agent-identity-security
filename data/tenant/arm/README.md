# data/tenant/arm

Shaped like Azure Resource Graph (`data` arrays) and ARM REST list responses (`value` arrays).

| File | What it does |
|---|---|
| `resourceContainers.json` | Subscriptions and resource groups |
| `resources.json` | Key vaults, managed identities, VMs, function apps, storage, Foundry accounts, projects and connections |
| `roleDefinitions.json` | Azure role definitions in scope |
| `roleAssignments.json` | Azure role assignments |
| `roleEligibilityScheduleInstances.json` | PIM-eligible Azure role assignments |
| `federatedIdentityCredentials.json` | Federated credentials on user-assigned managed identities, keyed by identity ID |
