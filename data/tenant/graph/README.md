# data/tenant/graph

Shaped like Microsoft Graph v1.0 list responses (`value` arrays). IDs are mock GUIDs that start with `00000000-`.

| File | What it does |
|---|---|
| `users.json` | Members and guests with sign-in activity and creation time |
| `userRegistrationDetails.json` | Registered authentication methods per user |
| `groups.json` | Groups with members and the role-assignable flag |
| `applications.json` | App registrations with owners, secrets, certificates and federated credentials |
| `servicePrincipals.json` | Service principals, managed identities, external apps and agent identities (with sponsors and blueprint) |
| `oauth2PermissionGrants.json` | Delegated consent grants |
| `roleDefinitions.json` | Directory role definitions |
| `roleAssignmentScheduleInstances.json` | Active directory role assignments (permanent and PIM-activated) |
| `roleEligibilitySchedules.json` | PIM-eligible directory role assignments |
| `conditionalAccessPolicies.json` | Conditional Access policies |
