# data/tenant/saas

Admin account exports from two fictional SaaS apps, so the scan can check that admins sign in through Entra ID.

| File | What it does |
|---|---|
| `ledgerline-crm.json` | CRM accounts, including a local admin and one linked to a disabled Entra account |
| `ticketwise-itsm.json` | IT service desk accounts, all on SSO |
