# data

A synthetic tenant for the fictional Kestrel Ridge Mortgage, generated by `idsec synth` from
`src/idsec/synth.py`, and the list of risks planted in it. CI fails if the files drift from the generator.

| File | What it does |
|---|---|
| `tenant/` | Raw files shaped like Microsoft Graph, Azure Resource Graph, Key Vault, Foundry and SaaS exports |
| `ground-truth.json` | The 47 planted risks (rule, subject, note). Only `idsec.labels` and the metrics read it |
